# BRNV Currency Converter · Android

Нативний безкоштовний конвертер валют на Kotlin і Jetpack Compose. Без акаунтів,
підписок і платних функцій. Android-версія [brnvconverter.com](https://brnvconverter.com).

## Поточні можливості

- Два початкові рядки EUR/USD; можна додати всі доступні валюти, без ліміту у чотири.
- Редагування суми в будь-якому рядку перераховує решту. Крапка й кома підтримуються.
- Вибір, пошук за кодом, локалізованою назвою та псевдонімами сайту.
- 77 фіатних валют із каталогу BRNV, прапорці й локалізовані символи валют Android.
- 19 криптовалют із каталогу сайту: BTC, ETH, USDT, USDC, BNB, SOL та інші;
  конвертація крипто ↔ фіат і крипто ↔ крипто через спільну базу USD.
- Перестановка та видалення через меню рядка; мінімум два рядки, без дублікатів.
- Обране, порядок валют і остання сума зберігаються на пристрої.
- Реальні курси ExchangeRate-API; кеш доступний після перезапуску без інтернету.
- Оновлення свайпом вниз, явна позначка збережених даних, повідомлення про помилки.
  Після успішного завантаження окремої плашки немає; статус кешу й помилки залишаються видимими.
- Мова й тема за пристроєм; кнопки в шапці дозволяють вибрати вручну або повернути
  системні налаштування. Українська, англійська, німецька, польська, французька,
  італійська, іспанська, португальська та спрощена китайська локалізації.
- Нейтральні назви валют, фільтри валют/крипто та адаптивна іконка із симетричними стрілками обміну.
- Опис із сайту під шапкою, компактні картки й кнопки, узгоджені меню теми та дій.
  Плавна поява мовного вікна, закриття селектора та зміни списку валют;
  анімації враховують системний масштаб тривалості.
- Кнопка «Оцінити додаток» та ненав’язливий Google Play In-App Review після достатнього користування.
- Кнопка «Наш сайт» відкриває BRNV у браузері.
- Кнопка «Підтримати BRNV» відкриває офіційну сторінку donate.html у браузері;
  підтримка добровільна, жодних платних функцій немає.
- Footer починається нижче першого екрана: порожнє місце розраховується за висотою вікна й вмісту.
- Віджет курсу на Jetpack Glance: незалежні пари, суми й теми для кожного екземпляра,
  фіатні/крипто-курси зі спільного кешу, статус кешу та дата. Натискання відкриває
  конфігурацію. Системний інтервал оновлення — 6 годин (точний час залежить від Android).

На першому запуску потрібне завантаження курсів. Застосунок не підставляє вигадані
курси, якщо немає ні мережі, ні кешу. Валюти, для яких провайдер не надав курс,
залишаються в каталозі сайту й отримують явне повідомлення про відсутній курс.

## Структура

```text
app/src/main/java/com/brnv/currencyconverter/
  BrnvApplication.kt            — спільні залежності на рівні процесу
  MainActivity.kt               — точка входу
  domain/                      — каталог, BigDecimal-розрахунки, стан конвертера
                                 та контракт/політика репозиторію курсів
  data/                        — HTTPS, JSON, атомарний файловий кеш, налаштування
  ui/converter/                — Compose UI, ViewModel і StateFlow
  ui/theme/                    — світла/темна палітра BRNV
```

UI → ViewModel → ExchangeRateRepository → RateDataSource + RateCache.
Провайдера можна замінити через `RateDataSource`. Формула перерахунку:
`amount × targetRate / sourceRate`; усі курси мають спільну базу USD.
Проміжні обчислення не округлюються до точності відображення.

Дискові та мережеві операції виконуються на `Dispatchers.IO`. Репозиторій
серіалізує конкурентні запити, спершу віддає кеш, враховує час наступного
оновлення API, обмежує ручні оновлення фіатних курсів одним запитом на годину та повтори після
помилки — одним на хвилину в поточному процесі. Запити не виконуються при
редагуванні суми або перестановці валют. Вибір криптовалюти може завантажити
її курси, якщо кеш застарів. Для встановлених віджетів Android запускає оновлення,
а мережеву роботу виконує worker Glance. Без віджетів періодичного оновлення немає.

Кеш записується через `AtomicFile` у внутрішнє сховище. Невеликий набір
налаштувань зберігається через `SharedPreferences` поза головним потоком,
з об’єднанням послідовних змін протягом 300 мс. Резервне копіювання вимкнене.

Крипто має окремий провайдер CoinGecko й окремий кеш; запит виконується лише коли
в конвертері вибрано криптовалюту, не частіше разу на 5 хвилин. Статуси
фіатних і крипто-курсів показуються окремо. Дані CoinGecko отримуються з публічного
endpoint сайту без вбудованих ключів. Його доступність і ліміти не гарантовані;
при помилці використовується крипто-кеш, фіатні курси продовжують працювати.

## Мова, тема й оцінка

Локалі змінюються через AppCompatDelegate та інтегруються із системними мовами
застосунків Android 13+. На Android 9–12 AppCompat зберігає вибір локально.
Тема має три режими: системний (типово), світлий і темний.

Автоматичний запит оцінки можливий після 3 днів, 3 сеансів (розділених принаймні
30 хвилинами), 10 подій конвертації та 3 хвилин у foreground. Послідовні введення
протягом 30 секунд рахуються як одна подія. Запит запускається лише у спокійний
момент, без відкритої клавіатури чи меню; пауза між спробами — 90 днів.
Лічильники зберігаються тільки локально, жодних аналітичних запитів немає.

Google Play сам визначає, чи показати системне вікно. Його завершення не означає,
що користувач написав відгук. Автоматичний запит пропускається для APK,
встановлених поза Google Play. Постійна кнопка відкриває сторінку застосунку
в Google Play (або браузері). Для справжніх оцінок потрібна опублікована сторінка;
перевіряти системний prompt слід через тестовий трек Play Console.

## Збірка

Поточні налаштування початкового проєкту збережено: minSdk 28 (Android 9),
compileSdk/targetSdk 37, AGP 9.4.1, Gradle 9.6.0, Kotlin Compose plugin 2.2.10,
Compose BOM 2026.02.01. Lifecycle узгоджено на 2.9.4 для ViewModel і
`collectAsStateWithLifecycle`. AndroidX JUnit 1.3.0 та Espresso 3.7.0 замінюють
застарілі тестові залежності для сумісності з поточним Android. Kotlin вбудований у AGP 9; окремий Android Kotlin
plugin не потрібен. Gradle daemon використовує JDK 25, Java source/target — 11.

Потрібні JDK 25, Android SDK Platform 37 та `local.properties` з локальним шляхом
до SDK. У терміналі Windows з налаштованим `JAVA_HOME`:

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

Друга команда потребує запущеного емулятора або підключеного Android-пристрою.
APK: `app/build/outputs/apk/debug/app-debug.apk`.

Тести використовують власні фікстури; не залежать від поточного курсу чи мережі.
Перевіряють конвертацію, редагування, кеш, конкурентні запити, помилки,
JSON/дискове збереження й основні Compose-сценарії.

Перевірено 12 жовтня: debug APK збирається, 22 модульні й 10 Android-тестів
проходять на емуляторі API 37. Перевіряються також свайп оновлення, перемикання
мови, збереження теми, крипто-курси та політика оцінки. Android Lint: 0 помилок,
9 попереджень (8 про новіші залежності, 1 про localeConfig лише для API 33+;
на старіших Android мову зберігає AppCompat). Додатково перевірено реальне
завантаження фіатних і крипто-курсів. На першому етапі перевірено повторний
запуск із вимкненою мережею, світлий екран та темний екран зі шрифтом 150%.
Після ущільнення інтерфейсу перевірено ширину 320 dp зі шрифтом 130%:
шапка переносить текст, кнопки переходять на нові рядки, весь вміст доступний прокручуванням.
Перевірено 15 жовтня: збірка першого віджета успішна, усі 13 Android-тестів
проходять на емуляторі API 37, включно з незалежними екземплярами віджета,
повторною конфігурацією та розташуванням footer поза першим екраном.
22 модульні тести проходять; Android Lint: 0 помилок, 13 попереджень.
MinSdk 28 і фізичний пристрій ще потребують окремої перевірки.
